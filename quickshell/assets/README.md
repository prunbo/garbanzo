# Assets

Place Zenless Zone Zero UI icons (PNG/SVG) here, e.g. downloaded from:
https://zenless-zone-zero.fandom.com/wiki/Category:UI_Icons

Recommended subfolders:
- icons/   -> menu/system icons
- wallpapers/ -> desktop wallpapers

The shell references icons by Material Symbols names by default; swap the
Text icon labels in modules/* for Image { source: "../assets/icons/..." } to use real assets.
