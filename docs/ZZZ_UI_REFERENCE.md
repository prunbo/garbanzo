# ZZZ UI Reference

Resumo técnico das telas de Zenless Zone Zero usadas como referência visual para o Garbanzo System.

## Estética geral
- Retro-futurista, urbano, analógico (VHS/TV CRT)
- Cantos chanfrados (cut corners) e arredondados misturados
- Cores vibrantes neon sobre fundo escuro
- Scanlines, fósforo de TV antiga, furos de fita de cinema
- Tipografia bold/italico, marcadores diagonais de velocidade

## Paleta sugerida
- Fundo: #0d0d12 / #16161d
- Superfície: #1e1e28 / #262633
- Acento primário (amarelo neon): #ffb300 / #ffcc00
- Acento secundário (laranja): #ff6b00
- Ciano neon: #00e5ff
- Magenta: #ff3bd4
- Verde-limão: #b6ff00 / #3ddc84
- Vermelho: #ff3b3b
- Texto: #f5f5f5, muted #8a8a9a

## Elementos recorrentes
- Barras de status inclinadas/dinâmicas
- Cápsulas pretas com recursos (energia, moedas, gemas)
- Molduras estilo fita VHS (furos perfurados)
- Grade de monitores CRT (matriz 5x5) para mapas
- Cartões de conquista com medalhas (ouro/prata/bronze)
- Nós de Mindscape Cinema (A-F) em estilo cassette
- Feed social com tags coloridas (INQUIRY/POST/INTEL)
- Televisão CRT diegética com relógio LED vermelho
- Calendário de papel com dia circulado
