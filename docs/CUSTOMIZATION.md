# Customization

## Colors
Edit `quickshell/config/Theme.qml` (accent, bg, surface, etc.) and `quickshell/shell.json`.

## Bar modules
Edit `quickshell/modules/bar/Bar.qml` and `shell.json` -> bar.modules.

## Dock pinned apps
Edit `shell.json` -> dock.pinned (list of app command names).

## Keybinds
Edit `hypr/keybinds.conf`.

## Wallpaper
Set in `shell.json` -> wallpaper.directory. Use swww: `swww img <path>`.
